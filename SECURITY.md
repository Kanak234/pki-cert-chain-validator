# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of `pki-cert-chain-validator` seriously. If you discover a vulnerability in certificate parsing, path validation, ASN.1/DER decoding, or cryptographic verification:

1. **Do not create a public GitHub issue.**
2. Report vulnerabilities privately via GitHub Security Advisories or by emailing security concerns to the maintainer.
3. Include detailed steps to reproduce the vulnerability, sample certificates or DER payloads triggering the defect, and potential impact analysis.
4. You will receive an initial response within 48 hours acknowledging receipt.
5. Once a fix is verified, a patched release and security advisory will be issued.
